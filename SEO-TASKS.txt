GOAL

Get https://karmyogi.hjlabs.in indexed and ranking on Google (and Bing) so more
people discover the app and sign up. Primary search intents to win:

WHAT THE PRODUCT IS (context the agent needs)
---------------------------------------------
- A static single-page web app (Vite + React 19 + TypeScript), NO backend.
- Talks to CNC machines via the Web Serial API => Chromium-only (Chrome, Edge,
  Opera, Brave). Firefox/Safari can't connect (but can still view the site).
- Hosted on Cloudflare Pages, project name "karmyogi", domain karmyogi.hjlabs.in.
- Deploy is a MANUAL wrangler upload of the built dist/ folder (NOT auto from
  GitHub). Credentials live in repo file secrets.cloudflare.env (gitignored).
  Deploy command (run from repo root, needs network egress):
      npm run build && set -a && . ./secrets.cloudflare.env && set +a && \
        npx wrangler pages deploy dist --project-name karmyogi --commit-dirty=true
- The app is auth-gated (Google sign-in) but first-time visitors get a multi-day
  free-explore grace window, so crawlers reach the app, not a hard login wall.
- GitHub repo: https://github.com/hemangjoshi37a/karmyogi  (README is rich/updated)
