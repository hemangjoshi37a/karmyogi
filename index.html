karmyogi — browser-based GRBL CNC controller & CAD/CAM workbench

Run your 3-axis GRBL machine straight from your browser over the Web Serial API — CNC carving & engraving, laser cutting, pen plotting, PCB isolation routing & drilling, auto-soldering, glue dispensing, pick & place, welding, spring coiling and 3D printing — with a live 3D toolpath visualizer, jog/DRO controller, GRBL $-settings manager and console. A free, modern, open Candle alternative. No installs, no drivers, no server.

  • GRBL · FluidNC · grblHAL · Marlin
  • DXF / STL / STEP / OBJ → G-code
  • Gerber + Excellon → PCB
  • 53 languages
  • Works offline (PWA)
  • Desktop & mobile
